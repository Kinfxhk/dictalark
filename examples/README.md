# Sample word lists · 示範詞表

Three small, self-written sample lists (English, Chinese read in Cantonese, Mandarin).
They are everyday words written for Dictalark; none is copied from a published or school
word list. They are dedicated to the public domain under
[CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).

三個自寫的小型示範詞表（英文、以粵語讀出的中文、普通話），全部是為 Dictalark 而寫的日常詞語，
並非抄錄自任何已出版或學校的詞表。以 CC0-1.0 貢獻至公眾領域。

Use them from the app ("Add sample lists" · 「加入示範詞表」) or import a file with
"Import CSV / TSV / JSON". Check one with the command-line tool:

```sh
node --import tsx packages/cli/src/main.ts validate examples/english-sample.json
```
